# CompactedGraphs

An early-stage Lean 4 project for experiments with compactified graphs, cylindrical coordinates, and related topology.

The production root is `CompactedGraphs.lean`, which currently imports `CompactedGraphs.Basic`. The project does not yet claim a completed publication theorem.

## Build

From this directory:

```powershell
lake build
```

Lean and Mathlib revisions are pinned by `lean-toolchain` and `lake-manifest.json`.
