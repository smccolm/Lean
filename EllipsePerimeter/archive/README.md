# EllipsePerimeter archive

This directory preserves non-production history from the consolidation of the
former EllipseLab project into the canonical `EllipsePerimeter` package.

- `development-history/` contains the numbered intermediate proof states and
  other proof-development records.
- `early-extraction/` contains useful source from the older partial
  EllipsePerimeter extraction, renamed to `.lean.txt` so Lake cannot treat it as
  production code.

The production import graph is rooted at `../EllipsePerimeter.lean`. Nothing in
this archive is imported or claimed as a current theorem module.
