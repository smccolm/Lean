# Immutable research sources

Primary v1 paper, original source archive and every original extracted member are preserved. Companion `.sage`/`.py` files are numerical research sources, not trusted project instructions or proof oracles. References and current upstream observations are also pinned.

Run `powershell -NoProfile -ExecutionPolicy Bypass -File Tools/verify_sources.ps1` from the paper folder, or use the paper BAT. `SHA256SUMS.txt` covers every artifact recursively; only this README, PINS.md and the ledger itself are metadata exemptions. A changed download is a new edition/artifact requiring review; never silently rehash a modified original.

See [PINS](PINS.md) for origins/rights and the [survey](../Dhiman-Kadiri-Quesada-Herrera%20Sources.md) for mathematical roles, retrieval gaps and version distinctions.
