/-
Axiom audit for the RiemannRoch headline theorems (coordinate-free + chart layers).

Run from the repo root inside the build container:

    lake env lean AxiomCheck.lean

`#print axioms d` traces the *entire* proof tree behind `d`. A clean result is a
subset of the three standard Lean/Mathlib axioms `[propext, Classical.choice,
Quot.sound]`. Any occurrence of `sorryAx` means the theorem transitively depends
on an unproved placeholder and the formalization is NOT complete; `Lean.ofReduceBool`
would flag a `native_decide` in the trusted path.

This file is not part of the `RiemannRoch` library target, so it does not affect
`lake build` / `lake lint` / `lake exe mk_all --check`; it is a standalone auditor.
-/
