Original coordinate generation, cotangent modules and representation points: Four further production modules prove that the actual matrix-coordinate classes generate the whole concrete representation algebra. The original multiplication law propagates membership in an algebra generated by matrix entries along the original multiplicative group generators. Consequently an original finitely generated abstract group has a finitely generated representation coordinate algebra, which is Noetherian over a Noetherian coefficient ring. The genuine Kähler differential module of that actual algebra supplies linear maps equivalent to the original adjoint cocycles, by composing Mathlib’s Kähler universal property with the original square-zero coordinate-derivation equivalence. For a finitely generated abstract group this genuine Kähler module is finite over the coordinate algebra. The actual original representation evaluation over the base ring is surjective; its literal point kernel has quotient isomorphic to the original coefficient algebra, with exact evaluation of each original coordinate class.
