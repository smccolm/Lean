# PostGM Work Area

Status: authorized. The first research program is selected, but no new theorem is yet claimed.

The Guth-Maynard foundation is frozen at exact commit `2ace9e7c09a69fdcd1edae1ab6deb7cb3b4df1be` and published annotated tag `gm-foundation-freeze-v1.0.1`. That commit passed the canonical release verifier from a fresh short-path clone. Hosted GitHub runs ended with external exit `143` before artifact upload; they provide no hosted PASS and are treated as optional, inconclusive evidence rather than a foundation blocker.

All new work must remain above that boundary. Do not edit the frozen `RiemannZeta/` proof modules, their public contracts, or the GM release evidence merely to make a post-GM experiment work.

The selected program is [Prime Shell](PrimeShell/README.md). Its first question is deliberately narrower than a new zero theorem:

> Does the exact Zeta23 prime-prime trace kernel admit control from the cumulative binary-correlation information obtainable from Guth-Maynard almost-all short intervals?

A rigorous negative answer is a valid Phase I result. It prevents a costly formalization of an arithmetic input that the spectral consumer cannot use.

The speculative route from improved pair information to the Riemann Hypothesis is not part of this program. Density-one results would not imply RH, and no such implication is claimed.
