# Riemann Zeta Formalization in Lean 4

[![Riemann Zeta Lean CI](https://github.com/smccolm/Lean/actions/workflows/riemann-zeta-ci.yml/badge.svg)](https://github.com/smccolm/Lean/actions/workflows/riemann-zeta-ci.yml)

Mechanized formalization of finite Dirichlet polynomial conjugation dualities, fourfold completed Zeta function orbits, and complex-valued Hardy-type phase normalization identities in **Lean 4** (pinned to toolchain `leanprover/lean4:v4.30.0`, package version `0.1.0`). The repository also contains an audit-clean conditional formalization of the Guth–Maynard (2026) Section 13.1 zero-density transfer, the native classical endpoint positive-slab theorem consuming the actual Type-I/Type-II dichotomy, native Type-II coverage and fourth-moment reduction, the completed-zeta-square smooth contour AFE and diagonal, the Duke–Friedlander–Iwaniec equations (2) and (9)–(30) with the optimized quadratic-divisor error theorem, and the Hughes–Young consumer culminating in `twistedZetaFourthMoment_native`. Source-faithful shared-language, matrix/trace, Fourier/Poisson, Hilbert–Schmidt first-trace, and quantitative smooth-reflection layers support the still-open Guth–Maynard large-values proof. The fully quantified symmetric Ingham/Huxley estimates, the complete `S₂/S₃` and energy chain, and the concrete final density theorems are not yet proved. The current production tree has no project postulate or admitted proof.

Author: **S. McColm**

## Package Structure
